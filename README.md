# OAMP Game Engine

Lightweight, pure Python game engine using:
- **OpenCV** — computer vision core
- **YOLOv5** — block detection
- **Mediapipe** — hand tracking

## Quick Start

```bash
pip install -r requirements.txt
python main.py
```

## Project Structure

```
oamp-game/
├── main.py           # Entry point
├── src/              # Source code
├── models/            # YOLOv5 models
├── references/        # Reference implementations
└── requirements.txt
```

## Requirements

- Python 3.8+
- OpenCV
- YOLOv5
- Mediapipe
